; ============================================================================
; DNS zone for aspekt.website (GitHub Pages custom domain)
; ============================================================================
;
; HOW TO IMPORT IN OVH:
;   1. Web Cloud -> Domeny (Domains) -> aspekt.website -> Strefa DNS (DNS zone)
;   2. Use the import/reset feature ("Import strefy DNS" / "Zresetuj strefę DNS")
;      and upload or paste the zone records below.
;   3. WARNING: import REPLACES the whole zone. This file preserves your OVH
;      email records (MX, SPF, DKIM, autoconfig, SRV) and only changes the web part.
;      (If OVH rejects the comment lines on import, copy only the records below.)
;
; WHAT IT DOES:
;   - Apex  aspekt.website  -> 4 x A records to GitHub Pages (185.199.108/109/110/111.153)
;   - www   aspekt.website  -> CNAME to ssledz.github.io
;   - Removes OVH's default redirect/parking TXT records ("1|www.aspekt.website"
;     and "3|welcome"), which broke the GitHub Pages HTTPS check.
;
; HOW TO VERIFY WITH dig (after import + DNS propagation):
;   dig +short aspekt.website A             # expect: 4 x 185.199.x.153
;   dig +short aspekt.website AAAA          # expect: empty (no stray IPv6)
;   dig +short www.aspekt.website CNAME     # expect: ssledz.github.io.
;   dig +short www.aspekt.website           # expect: the four GitHub IPs
;
; After the DNS is verified, force the GitHub HTTPS check:
;   Settings -> Pages -> Custom domain: remove aspekt.website, Save, re-add, Save.
; ============================================================================

$TTL 3600
@	IN SOA dns111.ovh.net. tech.ovh.net. (2091646078 86400 3600 3600000 60)
        IN NS     dns111.ovh.net.
        IN NS     ns111.ovh.net.
        IN MX     100 mx3.mail.ovh.net.
        IN MX     1 mx1.mail.ovh.net.
        IN MX     5 mx2.mail.ovh.net.
        IN A     185.199.108.153
        IN A     185.199.110.153
        IN A     185.199.109.153
        IN A     185.199.111.153
        IN TXT     "v=spf1 include:mx.ovh.com -all"
_autodiscover._tcp        IN SRV     0 0 443 mailconfig.ovh.net.
_imaps._tcp        IN SRV     0 0 993 ssl0.ovh.net.
_submission._tcp        IN SRV     0 0 465 ssl0.ovh.net.
